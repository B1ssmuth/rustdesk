# Доверие к сертификатам Windows RDP

YES Desk открывает системный MSTSC со строгой проверкой подлинности сервера и включённым CredSSP. Сообщение о недоверенном центре сертификации выдаёт MSTSC. Код завершения процесса не указывает причину отказа и не подтверждает успешность RDP-сеанса.

## Проверка

1. Сверьте полное DNS-имя в профиле YES Desk с DNS-именем в Subject Alternative Name сертификата RDP. При подключении по IP сертификат должен содержать соответствующий IP SAN. Проверьте отдельно DNS-имя RD Gateway, если он используется.
2. В MMC на сервере проверьте срок действия, наличие закрытого ключа и назначение Server Authentication (OID 1.3.6.1.5.5.7.3.1). Сверьте отпечаток с сертификатом активного listener RDP-Tcp. Для чтения настроек listener администратор может использовать команды ниже.
3. На клиенте проверьте, что цепочка заканчивается утверждённым доверенным центром, доступны промежуточные сертификаты и проверка отзыва. Сравните отпечаток и издателя с данными администратора по независимому каналу. Для выданной администратором копии открытого сертификата используйте certutil.

~~~powershell
Get-CimInstance -Namespace root/cimv2/TerminalServices -ClassName Win32_TSGeneralSetting -Filter "TerminalName='RDP-tcp'" |
    Select-Object TerminalName, SSLCertificateSHA1Hash, UserAuthenticationRequired
certutil.exe -verify -urlfetch .\rdp-server.cer
~~~

## Настройка доверия

- **Доменные компьютеры.** Выдайте сертификат компьютера через корпоративный AD CS с подходящим шаблоном и SAN. Настройте listener на выданный сертификат, включая доступ службы к его закрытому ключу. Разворачивайте доверенные корневые и промежуточные сертификаты на клиентах утверждённой групповой политикой. Оставьте требование NLA.
- **Тестовая среда.** Используйте DNS-имя тестового хоста, отдельный лабораторный CA и изолированные клиенты. Получите открытый сертификат CA из утверждённого источника и сверяйте отпечаток до распространения. Администратор тестового клиента добавляет доверие только в лабораторном контуре по его правилам. Самоподписанный сертификат, предъявленный неожиданно через MSTSC, следует считать ошибкой конфигурации.
