# Проверка YES Desk SFTP Explorer

Используйте тестовый Linux-сервер с OpenSSH, подсистемой `internal-sftp` и непривилегированной учётной записью. Создайте отдельно две тестовые папки, локальную и удалённую, и сверьте отпечаток ключа сервера перед первым подключением.

## Автоматическая проверка

Требуются Flutter 3.24.5, Docker и ssh-keygen. SSH/SFTP workflow выполняет Flutter tests и анализ на Windows x64 и Linux. Linux дополнительно запускает изолированные OpenSSH-контейнеры с доступом через loopback. Один контейнер принимает SFTP, другой отклоняет запрос подсистемы. Скрипт генерирует временный клиентский ключ и удаляет контейнеры, образ и временную директорию после прогона.

```bash
cd flutter
flutter pub get --enforce-lockfile
dart format --output=none --set-exit-if-changed lib/yesdesk/ssh test/yesdesk_sftp
flutter analyze --no-pub lib/yesdesk/ssh test/yesdesk_sftp
flutter test --no-pub --reporter expanded
cd ..
scripts/test-yesdesk-sftp-openssh.sh
```

Workflow **Full Flutter CI** создаёт Windows-артефакт `YES_Desk-Flutter-x64` с EXE/MSI и запускает проверку установки. Для ручного запуска используйте ветку `feature/yesdesk-sftp` и workflow `flutter-ci.yml`.

## Ручной сценарий

| Проверка | Ожидаемый результат |
| --- | --- |
| Войти в SSH Terminal, открыть проводник и обновить список | Открывается отдельный SFTP-канал того же SSH-соединения. Команды в терминале продолжают работать |
| Изменить ширину панели, скрыть и снова открыть | Панель сохраняет каталог и очередь. На узком окне она занимает рабочую область терминала до скрытия |
| Закрыть SFTP значком отключения внутри панели, затем открыть снова | Канал закрывается и открывается без разрыва терминала |
| Открыть SFTP из меню сохранённого подключения | Две панели. Слева выбрать корневую локальную папку, справа открывается домашний каталог сервера. Можно выбрать несколько файлов в каждой панели и перетащить их в соседнюю |
| Ввести путь с пробелами, перейти в родительский каталог, отфильтровать список, переключить сортировку | Список, размеры и даты соответствуют открытому каталогу. Клавиши F5, F2, Delete и Ctrl+A действуют при фокусе на удалённом списке |
| Загрузить несколько файлов через выбор файлов и перетаскиванием из ОС, скачать пустой файл и файл размером не менее 1 ГиБ | Очередь показывает байты, проценты и среднюю скорость. Сравнить контрольные суммы исходной и скачанной копий средствами ОС |
| Передать файл с именем `Отчёт за июль.txt` в обе стороны | Имя и содержимое сохраняются |
| Использовать на сервере имя `CON.txt` или символ `:` | Локальная запись отклоняется |
| Отменить ожидающую и активную передачу | Частичный файл не становится конечным. При обрыве SSH путь неудалённого временного файла отображается в очереди, если клиент успел получить дескриптор |
| Передать файл поверх существующего и отклонить подтверждение, затем повторить и согласиться | Первый файл остаётся целым до безопасной публикации подтверждённой замены |
| Переименовать файл в существующее имя, удалить непустой каталог и открыть каталог без прав | Сервер отклоняет операцию, исходные данные сохраняются |
| Удалить пустой каталог или файл | Операция требует подтверждения и отображает точный список элементов. Удаление выполняется без рекурсии |
| Изменить файл UTF-8, сравнить с исходным, сохранить и проверить свойства | Изменения видны, обычные Unix permissions сохраняются. Двоичные файлы и файлы свыше 512 КиБ отклоняются |
| Изменить текст другим клиентом между чтением и сохранением, в том числе на ту же длину | Редактор сообщает о конфликте, текст в редакторе остаётся доступен для копирования |
| Закрыть подключение на сервере, повторить с отключённой подсистемой SFTP | При обрыве активная операция завершается ошибкой. При отказе подсистемы терминал остаётся доступным |
| Открыть несколько вкладок SSH, поменять тему и язык интерфейса, открыть удалённый рабочий стол | Вкладки сохраняют независимые каталоги. Проверить обработку перетаскивания только на активной панели, читаемость RU/EN и светлой/тёмной темы, подключение и ввод в Remote Desktop |

## Ограничения протокола

Клиент передаёт обычные файлы. Удалённые каталоги удаляются только пустыми, ссылки отображаются со своими свойствами. Пакетная передача каталогов и возобновление частичных передач не входят в эту версию.

Удалённая запись производится во временный файл с правами 0600. Для замены требуется `posix-rename@openssh.com`. Без этого расширения новые файлы передаются через SFTP v3 RENAME с запретом перезаписи, а замена существующего файла завершается ошибкой. Проверка результата сравнивает размер и количество переданных байт. Редактор проверяет также исходное содержимое. SFTP v3 не предоставляет условный rename по версии файла. Процесс на сервере может изменить цель между последней проверкой и атомарной заменой. При замене клиент проверяет сохранение владельца, группы и обычных Unix permissions. Расширенные ACL и специальные биты Unix при замене не переносятся. Новые локальные файлы публикуются без перезаписи через MoveFile на Windows или hard link на Linux и macOS. Файловая система назначения должна поддерживать этот способ публикации.

При обрыве во время публикации обновите обе панели перед повтором. Сервер может успеть выполнить переименование до потери ответа. Удаляйте оставшиеся временные файлы `.yesdesk-*.part` после сверки с очередью и проверки, что передача завершилась. Используйте локальную папку, которую контролирует оператор. Dart проверяет канонический путь и ссылки, а на Windows также отклоняются имена устройств и альтернативных потоков.
