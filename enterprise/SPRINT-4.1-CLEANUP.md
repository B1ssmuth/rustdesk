# Аудит устаревших компонентов YES Desk Enterprise 4.1

| Компонент | Решение | Зависимости |
| --- | --- | --- |
| `management/enrollment_broker.py`, сертификатные параметры агента и шаблоны выпуска сертификатов | Оставить для совместимости и отката. Новые подключения 4.1 используют закреплённый транспортный ключ и действующую токенную регистрацию. | Прежняя регистрация, исторические сценарии и тесты. После сверки зарегистрированных устройств и сценария повторной регистрации можно убрать брокер из профилей поставки отдельным изменением. |
| `device_enrollment_certificates`, `corporate_endpoint_keys`, старые поля сертификата в разрешениях | Оставить для совместимости. | Миграции, отзыв прежней регистрации и возврат к прежнему Management API. Действующие сертификаты и записи остаются на месте. |
| Прежний OIDC/JWKS, AD-группы и маршруты `/v1` | Оставить для совместимости в окружениях с явно включённым режимом и для синтетической лаборатории. | `YESDESK_LEGACY_OIDC`, старые импорты, тестовый агент и исторические назначения. Новый снимок AD хранится отдельно и используется только как каталог. |
| Настройки и интерфейс unattended-доступа | Вывести из активного клиента и корпоративной выдачи разрешений 4.1. Сохранить старые поля БД и совместимые ответы API с недоступным unattended. | Старые политики и откат. Существующие обычные подключения по ID продолжают следовать настройкам RustDesk-транспорта. |
| Старые маршруты оценки прав и запуска `/v2/devices/{id}/connection` | Оставить для совместимости. | Ранее выпущенные клиенты. Рабочий корпоративный запуск проходит через `connection-options` и `session-grants`. |
| Дублирующие окна SSH/SFTP/RDP | Оставить рабочие окна. Навигация показывает их в административной области. | Сохранённые профили, операции SSH/SFTP и открытие RDP. |
| Единый корпоративный MSI и старые сценарии запуска пилота | Убрать из инструкции активной сборки, оставить для миграции и отката. | Передача владения службами, UpgradeCode, резервные копии и прежние установки. Удаление после инвентаризации пакетов и репетиции обновления. |
| Остатки RustDesk в пользовательских строках | Заменить обнаруженные доступные подписи в мобильных настройках на имя запущенного приложения. | Названия структур протокола, журналы диагностики, имена совместимых путей и лицензии сохраняются. |
| Старые сборочные скрипты, Sciter и упаковка для других ОС | Оставить до отдельной проверки публикаций и CI. | Подпись, сборка платформ и переносимые пакеты. Использовать два текущих скрипта для Windows x64. |
